# Another DOTA Synergy Predictor

A fully-fledged deployment of a school project that I worked on for my Neural Networks class. The goal of the project was to apply neural networks to build good teams in DOTA. To witness the network in action, [visit the app](https://dota-team-builder.vercel.app). Because the model runs on Render's free tier, you will have to wait for the service's initial cold start.

If you're interested to learn more, check out [this link](https://dota-team-builder.vercel.app/about). You will also find some interesting materials in the references directory of this repository.
